# Banki.shop — Интернет-магазин картин эпохи Возрождения

Тестовое задание: вёрстка страницы интернет-магазина по макету Figma.

## Технологии

- **Vue 2.7** (Options API + TypeScript)
- **Webpack 5** — сборка и dev-сервер
- **Yarn** — менеджер пакетов
- Шрифт **Merriweather** (Google Fonts)

## Установка и запуск

### Требования

- Node.js 16+
- Webpack

### Установка зависимостей

```bash
yarn install
```

### Запуск в режиме разработки

```bash
yarn dev
```

Приложение будет доступно по адресу [http://localhost:8080](http://localhost:8080).

### Production-сборка

```bash
yarn build
```

Результат сборки будет помещён в папку `dist/`.

## Функционал

1. **Поиск по названиям** — при вводе текста в строке поиска (в хедере) карточки товаров фильтруются по названию. Неподходящие карточки скрываются.

2. **Кнопка «Купить»** — три состояния:
   - *По умолчанию* — кнопка «Купить» (тёмно-коричневая `#382E2B`)
   - *Обрабатывается* (2 сек) — спиннер-прелоадер на кнопке
   - *В корзине* — иконка галочки и текст «В корзине» (фон `#5B3A32`). Повторный клик удаляет из корзины.

3. **Сохранение состояния корзины** — позиции, добавленные в корзину, сохраняются в `localStorage` и восстанавливаются после перезагрузки страницы.

4. **Модальное окно товара** — при клике на название или изображение открывается окно с:
   - Кратким описанием картины
   - Ценой
   - Слайдером из трёх изображений

5. **Навигация** — ссылка «Каталог» прокручивает к товарам, остальные пункты меню показывают уведомление-заглушку.

6. **Адаптивная вёрстка** — страница корректно отображается на экранах от 1920px до 360px.
